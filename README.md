# Sinuca Arena v0.2

Projeto Node.js com Express, SQLite e Socket.IO.

## Recursos
- login/cadastro
- fichas persistentes
- ADM libera/retira fichas
- desafios 1v1
- aposta e prêmio
- histórico
- compartilhamento
- mesa com mira e potência
- sincronização básica de tacadas

## Rodar
Node 18+:
`npm install`
`npm start`

ADM inicial: `admin` / `1234` (troque antes de publicar).

## Observação
A engine de mesa desta v0.2 é uma base jogável e não pretende reproduzir o código, arte ou identidade do 8 Ball Pool. Para produção competitiva, a física e validação de cada tacada devem continuar sendo refinadas no servidor.
